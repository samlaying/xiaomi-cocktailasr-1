# **Xiaomi-CocktailASR-1 — Target-Speaker Automatic Speech Recognition**

English | [中文](README.md)

---

## Introduction

Xiaomi-CocktailASR-1 is a target-speaker ASR model released by Xiaomi. Trained on large-scale multi-speaker data, it achieves SOTA performance on multiple multi-speaker test sets, while its single-speaker performance is on par with mainstream single-speaker ASR models. Xiaomi-CocktailASR-1 further supports negative-sample rejection and Chain-of-Thought (CoT) reasoning, providing an interpretable reasoning process over the recognition.

---

## Highlights 🎯

- **🏆 Multi-speaker SOTA**: SOTA performance on several mainstream multi-speaker test sets (AliMeeting, AMI, LibriMix, etc.).

- **🎯 Single-speaker compatible**: Single-speaker performance comparable to ordinary ASR models. A single model covers both single- and multi-speaker scenarios, eliminating the need to switch to a separate ASR model.

- **🚫 Negative-sample rejection**: Audio that does not contain the target speaker is rejected, effectively reducing false triggers.

- **🧠 Chain-of-Thought reasoning**: Supports a Chain-of-Thought (CoT) mode that provides an interpretable reasoning process for the recognition result.

## Quick Start

The model is packaged as a standard HuggingFace `trust_remote_code` model and can be loaded and run directly with `AutoModel`.

### Installation

```Bash
pip install torch torchaudio transformers soundfile
```

### Model file layout

After downloading from HuggingFace (see "Model Download" below), the model directory contains:

```Plaintext
Xiaomi-CocktailASR-1/                           # actual HuggingFace download path (snapshot dir)
├── config.json                    # MicAsrConfig (with auto_map, text_config, d2v2_config)
├── configuration_mic_asr.py       # Custom config class
├── modeling_mic_asr.py            # Custom model class (D2V2 audio encoder inlined)
├── feature_extraction_mic_asr.py  # Audio concatenation / feature processing
├── d2v2_config.json               # D2V2 audio encoder config
├── pytorch_model.bin              # All weights (D2V2 + Adapter + LLM)
├── tokenizer.json                 # Tokenizer
└── tokenizer_config.json          # Tokenizer config
```

### Single-utterance inference

Given a reference speaker clip (`ref.wav`) and a single- or multi-speaker mixed audio to be recognized (`target.wav`), the model transcribes only the target speaker. The concatenation of "reference audio + 1s silence + target audio" is performed internally and automatically.

```Python
from transformers import AutoModel

model = AutoModel.from_pretrained(
    "Ease3/Xiaomi-CocktailASR-1", trust_remote_code=True, torch_dtype="bfloat16"
).cuda().eval()
# "Ease3/Xiaomi-CocktailASR-1" is the HuggingFace repo ID (auto-downloaded to the local cache);
# you can also pass the path to an already-downloaded local directory

# Standard mode: directly returns the target speaker's transcription
# prompt: Based on the reference speech at the start, only transcribe the target speaker's speech into text.
text = model("target.wav", "ref_speaker.wav")
print(text)
```

`model(target, ref)` accepts audio file paths, a `numpy.ndarray`, or a `torch.Tensor` (16k mono; non-16k input is resampled automatically).

### Chain-of-Thought inference

In CoT mode, the model outputs its reasoning inside a `<think>` tag and the final result inside an `<answer>` tag:

```Python
# CoT mode
# prompt: Based on the reference speech at the start, only transcribe the target speaker's speech into text. Please think step by step and provide a detailed reasoning process in <think> </think>.Please output the final answer in <answer> </answer>.
text = model("target.wav", "ref_speaker.wav", cot=True)
print(text)
```

### Negative-sample rejection

When the reference speaker is not present in the mixed audio, the model outputs empty text (rejection). Usage is identical to standard inference — no special argument is needed:

```Python
# The speaker of the reference audio is not in target → the model outputs empty text
text = model("target.wav", "ref_speaker.wav")
print(text)  # → ""
```

### Batch inference

Transcribe a 5-column TSV (`utt_id, wav, text, ref_wav, ref_id`) directly — no pre-concatenation needed. The script calls `model(wav, ref)` per row (the ref+silence+target concatenation happens inside the model) and processes rows strictly in file order:

```Bash
CUDA_VISIBLE_DEVICES=0 python tools/test_batch_scp.py \
    --hf_model_dir Ease3/Xiaomi-CocktailASR-1 \
    --input_scp scp_text_ref.all \
    --output_file out/result.txt
# add --cot for Chain-of-Thought mode
```

Produces `out/result.txt` (hypotheses) and `out/text` (references) in the same directory for scoring.
